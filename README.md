# Fora do Feed

Plataforma web desenvolvida como parte do Trabalho de Conclusão de Curso em Ciência da Computação na UFOP.

O **Fora do Feed** coleta conteúdos de redes sociais que mulheres não gostariam de continuar vendo em seus feeds. Os dados coletados são utilizados na pesquisa para identificar padrões e gerar visualizações e resultados agregados.

## Como executar

### Requisitos

- Node.js
- npm

### Instalação

Clone o repositório e instale as dependências:

```bash
npm install
```

### Execução

Inicie o servidor:

```bash
npm start
```

### Testes

Para executar os testes automatizados:

```bash
npm test
```
